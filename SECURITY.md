# Security Policy

## Supported Versions

The following versions of `ac-bot-avatar` packages currently receive security updates:

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not open a public issue**.

Instead, report it privately by:

1. **Opening a [GitHub Security Advisory](https://github.com/AC-Andrade/ac-bot-avatar/security/advisories/new)** (preferred)
2. Or emailing the maintainer directly at a private contact (to be added)

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested fix (optional but appreciated)

## Response Timeline

| Step                     | Target                 |
| ------------------------ | ---------------------- |
| Acknowledgement          | Within 48 hours        |
| Initial assessment       | Within 5 business days |
| Resolution or workaround | As soon as possible    |

## Scope

This policy applies to all packages within this monorepo:

- `@ac-andrade/ac-bot-avatar-core`
- `@ac-andrade/ac-bot-avatar-assets`
- `@ac-andrade/ac-bot-avatar-utils`
- `@ac-andrade/ac-bot-avatar-react`

## Disclosure Policy

Once a fix is released, we will publish a security advisory with full details. We follow **coordinated disclosure** — a reasonable time window will be given before any public disclosure.

Thank you for helping keep this project secure.
