# Regras Gerais para Agentes de IA

1. **Linguagem**: TypeScript rigoroso.
2. **Estilo de Código**: Modular, sem dependências desnecessárias, preferindo funções puras.
3. **Idiomas**: Utilize sempre Português do Brasil para interações com o usuário e documentações, mas código (variáveis, métodos) preferencialmente em Inglês.
4. **Segurança**: Execute `snyk_code_scan` ao adicionar novos componentes ou lógicas complexas.
