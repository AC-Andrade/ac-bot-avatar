# Política de segurança

## Versões suportadas

| Versão | Suporte |
| ------ | ------- |
| 1.x    | Sim     |
| < 1.0  | Não     |

Reporte vulnerabilidades em privado por uma [GitHub Security Advisory](https://github.com/AC-Andrade/ac-bot-avatar/security/advisories/new). Não abra uma issue pública com detalhes exploráveis.

Inclua descrição, reprodução, impacto e, quando possível, uma correção sugerida. O objetivo é confirmar o recebimento em até 48 horas e fornecer uma avaliação inicial em até cinco dias úteis.

Antes de cada release, o pipeline executa auditoria de dependências e Snyk Code. Se o CLI indicar `SNYK-0005`, autentique a estação com `snyk auth` e repita a análise.
